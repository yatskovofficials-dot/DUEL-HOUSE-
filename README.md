# DUEL HOUSE 3D — ARENA EDITION

Профессионально оформленная браузерная 3D-арена для двух игроков на одной клавиатуре.

## Запуск
- Откройте `index.html` через VS Code Live Server или опубликуйте проект через GitHub Pages.
- Three.js загружается с jsDelivr, поэтому нужен интернет.

## Управление
### Игрок 1
- WASD — движение
- Space — прыжок
- F — стрелять
- G — ближняя атака
- Q / E — смена оружия
- T — призвать Титана

### Игрок 2
- Стрелки — движение
- Right Shift — прыжок
- Enter — стрелять
- . — ближняя атака
- [ / ] — смена оружия
- M — призвать Титана

## Особенности
- 3D-арена с комнатами, архитектурой, неоновыми акцентами и динамическим освещением.
- Локальный PvP для двух игроков.
- Пять видов оружия: Pulse, Scatter, Rail, RPG, Arc.
- Разрушаемые сегменты стен и мебель с обломками.
- Босс Titan с отдельной полосой здоровья, преследованием и дальними атаками.
- Эффекты попаданий, вспышки, частицы, тряска камеры.
- Счёт и матчи до пяти побед.
